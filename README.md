# Style Studio

Save an art style once (sample artwork + a style description), then turn any photo — or a described scene — into that style using Google's Gemini image models.

Live: https://jimmywilson1979-arch.github.io/style-studio/

- Runs entirely in the browser; your Gemini API key is stored only on your device.
- Styles and gallery are kept in the browser (IndexedDB). Use Settings → Backup to export/import styles.
